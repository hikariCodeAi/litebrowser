# LiteBrowser 性能报告

更新日期：2026-10-21。

LiteBrowser 是基于 Chromium 的精简浏览器，专注内存优化。本报告区分已归档的历史测试与当前发行版本的验证状态。

| 平台 | 性能验证状态 |
| --- | --- |
| macOS arm64 | 尚未完成性能对比测试，暂不提供内存节省比例或速度提升结论。 |

## 历史 Linux 受控测试

测试日期：2026-10-14（北京时间）。环境为 Ubuntu 22.04、Linux 6.8、x86_64、48逻辑线程和约64GiB内存，以非root账号和浏览器沙箱运行，通过cgroup v2记录物理内存。

比较对象为相同Chromium 155.0.8059.39内核的原始基线与LiteBrowser八层优化候选版。下表是一次已归档的100循环合成负载测试记录；每循环分配TypedArray缓冲并生成、释放Blob，总计处理约500MB数据。它是用于观察内存行为的合成测试，不是完整视频编码、真实业务导出或日常浏览的性能结论。

| 记录指标 | 原始基线 | LiteBrowser历史候选版 |
| --- | ---: | ---: |
| 时间加权平均物理内存 | 765.73 MiB | 309.45 MiB |
| 记录到的物理内存峰值 | 1014.02 MiB | 397.84 MiB |
| 结束空闲内存减去初始空闲内存 | +592.92 MiB | -8.15 MiB |
| 测试总耗时 | 78.30秒 | 78.14秒 |
| 完成循环数 | 100 | 100 |

上述记录中平均内存下降约59.59%，峰值下降约60.77%。这些数值只描述该次Linux合成负载，不能据此保证Mac版、Windows版、任意网站或真实生产业务具有相同收益；单次负差值也不能证明不存在所有类型的内存泄漏。

另有历史Web平台确定性检查记录：两份Linux构建均完成31项导航、脚本、网络、布局、图片、媒体等检查，记录中未发现用例间的功能回归。这些检查覆盖有限，不能替代完整网站兼容性验证。

## 版本与结果的对应关系

上述历史Linux候选版先于当前品牌、授权和静默更新功能的后续改动。当前Mac版或Linux 1.0.0预览版完成构建或基础功能检查，不代表它们已完成同等性能测试。Linux版本暂通过发布仓库手动更新。后续结果将分别注明平台、浏览器版本、测试方法与测量范围。
